👗 AI-Powered Personal Stylist

An intelligent fashion recommendation web application that helps users discover personalized outfits based on their body type, clothing preferences, favorite colors, budget, and occasion.

🌟 Project Overview

AI-Powered Personal Stylist is a web-based fashion recommendation system designed to make online shopping easier and smarter.

The application combines user preferences, product catalogue information, AI-based photo analysis, and recommendation logic to suggest coordinated outfits that match individual styling requirements.

✨ Key Features

- **Personalized Recommendations:** Suggests outfits based on user preferences, style, budget, and occasion.
- **AI Photo Analysis:** Analyzes uploaded photos for clothing colors, patterns, textures, and style-related visual cues.
- **Outfit Composition:** Recommends coordinated four-piece outfits.
- **Product Catalogue:** Displays fashion products with images, categories, names, and prices.
- **Smart Budget Filtering:** Helps users find products within their preferred budget.
- **Weather & Occasion Awareness:** Supports context-aware styling recommendations.
- **User Profile:** Stores personal styling preferences and clothing requirements.
- **My Outfits & History:** Supports saving outfits and viewing recommendation history.
- **Fashion Dashboard:** Provides an overview of the user's styling activity.

🛠️ Technologies Used

| Component | Technologies |
|---|---|
| Frontend | JavaScript, Vite |

| AI & Image Analysis | AI-based photo analysis |

🏗️ System Architecture

The application follows a modular five-layer architecture:

1. Frontend – User interface and interaction.
2. FastAPI Backend – Handles application requests and API operations.
3. Services Layer – Recommendation, preferences, image processing, weather, and AI styling.
4. Database & Product Catalogue – Stores user and product information.
5. External Services – Optional AI and contextual integrations.

⚙️ How It Works

1. Users create a profile and enter their fashion preferences.
2. Users can optionally upload a photograph for AI-based style analysis.
3. The system collects user preferences and available product information.
4. Recommendation logic filters products according to style, color, budget, and occasion.
5. Compatible products are combined into coordinated outfits.
6. Users can explore, save, and review outfit recommendations.

🚀 Getting Started

# Prerequisites

- Python 3.x
- Node.js and npm
- Git

# Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install backend dependencies**

```bash
pip install -r requirements.txt
```

**4. Install frontend dependencies**

```bash
cd frontend
npm install
```

**5. Start the frontend**

```bash
npm run dev
```

Run the FastAPI backend separately using the application's configured entry point.

*Note: Update folder names and backend startup commands according to your actual repository structure.*
